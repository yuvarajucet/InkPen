# InkPen - Quick Reference Card

## 🎯 Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `P` | Pen Tool |
| `E` | Eraser Tool |
| `H` | Highlighter Tool |
| `S` | Shapes Tool |
| `T` | Text Tool |
| `C` | Cursor Tool |
| `Ctrl+D` | Delete All |
| `Escape` | Exit Application |

---

## 🛠️ Tools Quick Guide

### Cursor (C)
- **Purpose**: Deactivate drawing mode
- **Use**: Switch between drawing and regular mouse interaction
- **Tip**: Click when you want to interact with other applications

### Pen (P)
- **Purpose**: Freehand drawing
- **Customization**: Size (1-50px), Color (any)
- **Tip**: Perfect for annotations and notes

### Eraser (E)
- **Purpose**: Remove strokes
- **Behavior**: Removes entire connected line
- **Tip**: Click/touch a stroke to erase it and all connected strokes

### Highlighter (H)
- **Purpose**: Transparent highlighting
- **Customization**: Size (1-50px), Color (with transparency)
- **Tip**: Great for marking important text

### Color Picker
- **Purpose**: Select drawing color
- **Method**: Click color preview button
- **Tip**: Supports any RGB color

### Shapes (S)
- **Options**: Line, Rectangle, Circle, Ellipse
- **Method**: Draw from start point to end point
- **Tip**: Hold and drag to create shapes

### Text (T)
- **Purpose**: Add text annotations
- **Method**: Click location, enter text
- **Tip**: Font and size adapt to pen settings

### Clear (🗑️)
- **Purpose**: Delete all drawings
- **Shortcut**: `Ctrl+D`
- **Tip**: Clears everything instantly

## ⚙️ Settings Guide

### Pen Size
- **Range**: 1-50 pixels
- **Controls**: Slider or Spinbox
- **Default**: 2 pixels
- **Tip**: Smaller = more detail, Larger = faster drawing

### Color Selection
- **Method**: Click the color button
- **Range**: Full RGB spectrum
- **Alpha**: Adjustable for highlighter
- **Tip**: Use contrasting colors for visibility

### Shape Type (when using Shapes tool)
- **Line**: Straight line between two points
- **Rectangle**: Rectangular shape
- **Circle**: Perfect circle
- **Ellipse**: Oval/elliptical shape

## 💡 Pro Tips

### Drawing Quality
- Use pen size 2-4 for detailed work
- Use size 6-8 for presentations
- Use highlighter size 6-10 for highlighting

### Efficiency
- Use Cursor tool to quickly deactivate drawing
- Press Ctrl+D for instant clear instead of clicking button
- Use keyboard shortcuts for faster tool switching

### Accuracy
- Use pen size 1-2 for pixel-perfect annotations
- Draw slowly for smoother lines
- Use shapes tool for perfect geometric forms

### Visibility
- Use black on light backgrounds
- Use yellow/white for dark backgrounds
- Use blue (#0078D4) for professional presentations

## 🚀 Getting Started

### Installation
1. Download and extract `InkPen.zip`
2. Run `InkPen.exe`
3. Start drawing!

### First Drawing
1. Launch InkPen
2. Click **Pen** tool
3. Adjust pen size if needed
4. Click and drag on screen
5. Done! Your drawing appears

### Common Tasks

**Highlight Important Text**
1. Select Highlighter (H)
2. Adjust size
3. Select yellow color
4. Draw over text

**Draw Diagram**
1. Select Shapes tool (S)
2. Choose shape type (Rectangle/Circle)
3. Draw multiple shapes
4. Use Pen for connecting lines

**Add Annotation**
1. Select Text tool (T)
2. Click where to place text
3. Type your text
4. Click elsewhere to finish

**Undo Mistake**
1. Use Eraser (E)
2. Click/touch the stroke to remove

**Start Fresh**
1. Press `Ctrl+D` or click Clear
2. All drawings removed
3. Ready for new drawing

## 🆘 Troubleshooting

### Can't Draw
- ✅ Try selecting different tool
- ✅ Check if cursor mode is active - switch to Pen
- ✅ Restart application

### Drawing Appears Faint
- ✅ Check color selection - might be too light
- ✅ Try black or darker color
- ✅ Increase pen size

### Eraser Not Working
- ✅ Make sure Eraser tool is selected
- ✅ Click on the stroke line itself
- ✅ Eraser removes connected strokes as a group

### Application Won't Start
- ✅ Try running as Administrator
- ✅ Check Windows Defender isn't blocking it
- ✅ Try restarting computer

### Toolbar Disappeared
- ✅ Restart InkPen
- ✅ Look for InkPen in taskbar
- ✅ Alt+Tab to find window
