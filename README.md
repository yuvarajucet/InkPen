# InkPen

InkPen is a Windows overlay writing and annotation application built with Python and PyQt6.

## Features

- Always on top toolbar
- Draw over any application
- Pen tool
- Highlighter
- Shape tools
- Text tool
- Stroke eraser
- Clear all drawings
- Adjustable pen size
- Color picker

## Build

```bash
pip install -r requirements.txt
pyinstaller build.spec
```

## Run

```bash
python app.py
```
